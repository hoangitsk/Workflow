# Thêm giọng F5-TTS

Với mỗi kênh, tạo một cặp file cùng tên:

- `kenh_a.wav`: đoạn mẫu giọng sạch, chỉ có một người nói và bạn có quyền sử dụng.
- `kenh_a.txt`: transcript của chính đoạn WAV, đúng từng chữ và dấu câu.

Ví dụ: `kenh_a.wav` đi cùng `kenh_a.txt`. ID để web gọi là `kenh_a`.

Không đưa hai file thật vào Git hay Space công khai. Khi chủ dự án gửi cặp file, chỉ tải chúng lên Space Hugging Face đang ở chế độ Private.
